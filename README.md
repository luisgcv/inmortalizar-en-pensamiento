# inmortalizar-en-pensamiento
# ¿Quiénes somos?

¿Quién soy?

¿Cuál es mi perspectiva de la vida?

¿Quién quiero ser?

¿Soy feliz?

¿Soy alguien?

¿Represento algo?

Este repositorio no busca demostrar inteligencia ni perfección. Es un lugar para escribir pensamientos sinceros y preservar aquello que somos.

No hace falta escribir bien.

No hace falta seguir una estructura.

No hace falta siquiera responder las preguntas anteriores.

Escribe lo que quieras.

Puedes permanecer en el anonimato o decir quién eres.

Si vienes a leer, bienvenido.

Si decides escribir, deja una parte de ti.

Porque toda vida merece ser inmortalizada en pensamiento.
